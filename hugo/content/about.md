I write about programming, tooling, and the small decisions that make
software easier to live with.

This site is deliberately simple: Hugo renders every page as static HTML,
and React is only used for the few widgets that genuinely need state.

## Colophon

- Static site generator: Hugo (extended)
- Theme base: Blowfish, heavily customized
- Interactive islands: React + TypeScript, built with Vite
- Hosting: GitHub Pages, deployed by GitHub Actions
